# Bellissimo Beauty Salon — Vercel

## Deploy
1. Upload this folder to GitHub (or import the ZIP contents into Vercel).
2. In Vercel choose **Import Project** and select the repository.
3. No build command is required. Vercel detects `vercel.json` and the Python function in `api/index.py`.
4. Deploy.

The existing Flask site, templates, CSS, JavaScript, price list, WhatsApp booking and 2GIS link are preserved.

## Local test
```bash
pip install -r requirements.txt
python test_site.py
python app.py
```
